# RepoDNA v1.4.0 — Official release

**Released:** October 15, 2026  
**Tag:** [`v1.4.0`](https://github.com/sanskarIN/RepoDNA/releases/tag/v1.4.0)  
**Status:** Stable public release (neither draft nor prerelease)  
**Files:** 15 downloadable release assets, including `SHA256SUMS.txt`.

## What's new

- Brand-new hand-authored, non-AI SVG RepoDNA helix/graph logo, matching PWA/desktop app icons, and startup splash screen with reduced-motion support.
- The official PayPal.Me [support link](https://paypal.me/SanskarCodes) alongside Buy Me a Coffee and Razorpay.
- Fixed deep-link search parameters containing additional question marks and startup keyboard-focus behavior.
- Corrected GitHub Action documentation and synchronized Rust/TypeScript version packaging.

Read the [complete release notes](release-notes.md) or the [GitHub Release](https://github.com/sanskarIN/RepoDNA/releases/tag/v1.4.0).
