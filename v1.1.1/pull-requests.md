## #16 Release v1.1.1

[https://github.com/sanskarIN/RepoDNA/pull/16](https://github.com/sanskarIN/RepoDNA/pull/16) · branch `release-v1.1.1`

Website link (https://sanskarin.github.io/, for more open-source projects) now appears in:

the About & support page and the sidebar "Made by the Sanskar" credit (web version and desktop app);
repodna version;
README, SUPPORT.md, the FAQ, the docs index and MAINTAINERS.md;
the end of every release's notes.

Bugs fixed:

repodna config path printed an extra hint along with the path, which broke scripts that use $(repodna config path).
A local AI program that left a background process running made RepoDNA wait for that process to exit (20+ seconds in the test) instead of returning the answer.
Repositories where no architecture could be identified showed "unavailable confidence" in the terminal, reports and web interface.
About 30 wording mistakes in reports, the terminal and the web interface: "1 files", "1 commits", "1 analyses", "0 test files. Run them with…", "(root)/", and "Looks like a Unknown".
One of these mattered more: pip install -e . got a second period, so it read as pip install -e .., a different command.
Release notes generated by the release workflow lacked the web version link.

Checks: locally, 595 Rust tests and 67 web tests passed, along with clippy, formatting, docs, the third-party notices, the dependency checks, the desktop checks and a browser check of every web view. On GitHub, the [CI run](https://github.com/sanskarIN/RepoDNA/actions/runs/37195321248) and the [trial release build](https://github.com/sanskarIN/RepoDNA/actions/runs/37195350448) both passed.
