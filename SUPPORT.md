# Getting help

## Read the documentation

- [Getting started](docs/getting-started.md): install RepoDNA and analyze a repository in
  five minutes.
- [Troubleshooting](docs/troubleshooting.md): common problems and what to do about them.
  `repodna doctor` checks your installation and says what to fix.
- [FAQ](docs/faq.md) and the [full documentation](docs/index.md).

## Ask a question or report a problem

Open an [issue](https://github.com/sanskarIN/RepoDNA/issues/new/choose) and choose the
template that fits: a bug, a wrong result, a feature idea, a language, a performance
problem, or the documentation. Please include the output of `repodna version --json` and
`repodna doctor --json`, the command you ran, and what you expected.

Support is given on a best-effort basis by the maintainers and the community.

## Report a security vulnerability

Please do not open a public issue. Follow [SECURITY.md](SECURITY.md) to report it
privately.
