# RepoDNA v1.4.5 release qualification

**Candidate only.** This checklist prepares a maintenance release after v1.4.4.
It does not create a version tag, publish an artifact, or claim release approval.
The published stable version remains v1.4.4 until a tagged release succeeds.

## Scope and version choice

Choose **v1.4.5** for the integrated correctness, reproducibility, privacy,
offline-model evaluation, and documentation changes. Do not market this as a
new generative language model or imply measured improvements in factual accuracy.

Reserve **v1.5.0** for a separately scoped user-visible milestone, such as
verified repository-impact summaries or a substantially improved native explanation
experience. Before choosing that milestone, require representative, licensed data,
an independent repository-disjoint test split, documented CPU/RAM/latency budgets,
a backwards-compatibility review, and a reviewed migration story. A new semver
minor alone does not justify quality claims.

## Native AI regression and privacy gates

- [ ] Run `cargo fmt --all --check`, `cargo clippy --workspace --all-targets --locked -- -D warnings`,
  and `cargo test --workspace --locked` on the candidate.
- [ ] Verify local-only `ai.provider = "native"` with and without an opt-in
  checkpoint; repository-controlled config cannot activate it.
- [ ] Verify checkpoint bounds, format validation, evidence ID preservation,
  deterministic rank ordering, cited extractive output, cache provenance, and
  no source excerpts in the native digest.
- [ ] Verify train/holdout alias rejection, duplicate annotations, shuffled
  training order, and direct evaluation grouping with aliases.
- [ ] Verify answerability threshold, Brier/log-loss/calibration-bin tests
  with deliberately labeled offline fixtures. Do **not** publish numerical
  accuracy claims from synthetic examples.
- [ ] Review representative, independently labeled and appropriately licensed
  repositories before making broader relevance/quality claims; track
  uncertainty rather than inventing measurements.
- [ ] Recheck no telemetry, automatic checkpoint downloads, API-key
  requirements, or remote repository uploads were added to native mode.
