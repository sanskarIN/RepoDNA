## Automated preflight on Windows

Download the three trial artifact ZIPs, extract each separately, and run from
a checkout of the **same finalization commit**:

```powershell
& .\packaging\release\check-v1.5.3-windows-trial.ps1 `
  -Architecture x64 `
  -Directory "C:\RepoDNA-QA\desktop-Windows" `
  -ChecksumFile "C:\RepoDNA-QA\trial-sha256sums\SHA256SUMS.txt"

& .\packaging\release\check-v1.5.3-windows-trial.ps1 `
  -Architecture arm64 `
  -Directory "C:\RepoDNA-QA\desktop-Windows-arm64" `
  -ChecksumFile "C:\RepoDNA-QA\trial-sha256sums\SHA256SUMS.txt"
```

The helper fails if the checksum manifest is incomplete, the expected MSI or
NSIS setup EXE is missing, a SHA-256 differs, or the NSIS version resource
does not show `CompanyName = RepoDNA`, `ProductName = RepoDNA` and the
expected file/product version. **It does not install or execute either
package**; passing it does not complete native QA. Do not treat trial
binaries as published releases or bypass operating-system security prompts.
