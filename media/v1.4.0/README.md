# RepoDNA v1.4.0 — original logo (in development)

These are the original v1.4.0 identity and launch assets, implemented in
[RepoDNA's v1.4.0 source](https://github.com/sanskarIN/RepoDNA/tree/main).

| Asset | Format | Purpose |
|---|---|---|

The logo depicts two intersecting DNA strands and three code-graph
connections, in navy, blue, and teal. Its source is original SVG geometry
(`path`, `circle`, and simple vector shapes), **not AI-generated imagery**.
The PNG was rendered from the same vector mark as the v1.4.0 application icons.

**Suggested alt text:** "RepoDNA icon: a blue and teal DNA double helix with
three connecting graph edges on a navy rounded square."

The [v1.4.0 screenshot collection](../../screenshots/v1.4.0/README.md) contains real web interface and generated documentation captures. The [successful capture job](https://github.com/sanskarIN/RepoDNA/actions/runs/38688707790) verifies all 10 PNG assets (promotional artwork, two cards and seven screenshots). Existing v1.3.3 screenshots were not relabeled.
