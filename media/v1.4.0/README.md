# RepoDNA v1.4.0 — original logo (in development)

These are the source assets for RepoDNA's upcoming v1.4.0 identity.
The release is **not published**. The branding has been implemented on
[`release-v1.4.0-development`](https://github.com/sanskarIN/RepoDNA/tree/release-v1.4.0-development).

| Asset | Format | Purpose |
|---|---|---|
| [Brand mark](branding/repodna-mark.svg) | Hand-authored SVG | Scalable app icon |
| [Wordmark](branding/repodna-wordmark.svg) | Hand-authored SVG | GitHub and project identity |
| [512px brand mark](branding/repodna-mark-512.png) | PNG | Social cards and previews |

The logo depicts two intersecting DNA strands and three code-graph
connections, in navy, blue, and teal. Its source is original SVG geometry
(`path`, `circle`, and simple vector shapes), **not AI-generated imagery**.
The PNG was rendered from the same vector mark as the v1.4.0 application icons.

**Suggested alt text:** "RepoDNA icon: a blue and teal DNA double helix with
three connecting graph edges on a navy rounded square."

Existing v1.3.3 screenshots have not been relabeled as v1.4.0. The new
release's web, desktop, and mobile screenshots will be added to
`screenshots/v1.4.0` when the version is validated.
