# RepoDNA v1.3.3 — media assets

Images for the 1.3.3 patch release. PNG generation and image-size verification
completed in [GitHub Actions run 38664630144](https://github.com/sanskarIN/RepoDNA/actions/runs/38664630144)
using source commit `f89250a6472a94e083cec0418351f007ccc95973`. The graphics use the same blue, charcoal, and
light neutrals as the RepoDNA web interface. Editable SVGs are retained alongside
high-resolution PNG exports. All images are covered by the repository's
[Apache-2.0 license](../../LICENSE).

## Promotional designs

| Asset | Size | Suggested use |
|---|---|---|
| [Launch banner](promo/launch-16x9.png) ([SVG](promo/launch-16x9.svg)) | 3200 × 1800 | X, LinkedIn, Facebook, article covers |
| [What's new](promo/whats-new-1x1.png) ([SVG](promo/whats-new-1x1.svg)) | 2160 × 2160 | Instagram, LinkedIn |
| [Highlights portrait](promo/highlights-4x5.png) ([SVG](promo/highlights-4x5.svg)) | 2160 × 2700 | Instagram, Threads, stories |

The promotional graphics are *illustrations*, not screenshots of a UI, and do not
claim to show real repository metrics or test-run statistics beyond the successful
17-job validation recorded during v1.3.3 release preparation.

## Project DNA cards

| Card | Size | Description |
|---|---|---|
| [Light](cards/dna-card-light.png) | 2400 × 1260 | Real card from the 1.3.3 source, light palette |
| [Dark](cards/dna-card-dark.png) | 2400 × 1260 | Real card from the 1.3.3 source, dark palette |

Cards are generated with the version's actual Rust command-line implementation
using `repodna card . --format png --privacy public`, including `--dark` for the
dark card. No repository metrics are invented.
